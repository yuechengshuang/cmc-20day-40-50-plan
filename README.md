## 三、规模与质量数据

- **287 道题**：257 道专项题库 + 30 道模拟卷，**全部配有零基础详细解析**
- 难度分布：★ 18 / ★★ 204 / ★★★ 35，**无 ★★★★ 及以上**（严格贯彻"基础题 > 常规题 > 中档题 > 难题"）
- 每个题型都是「**1 道母题 + ≥2 道变式 + "这一类题我到底应该记住什么"**」
- 每道题固定 **10 个字段**：题目 / 考查知识点 / 题型识别 / 需要记住的公式 / 解题思路 / 详细解答 / 最终答案 / 易错点 / 同类题识别技巧 / 一句话总结
- 全书 **0 处**"显然 / 易知 / 计算即得"等跳步用语；【详细解答】均 ≥200 字，不跳步
- **29,983 个行内公式 + 2,716 个独立公式行**，全部转换为 **Word 原生公式（OMML）**，0 处转换失败、0 处 LaTeX 残留

## 五、如何重新生成文档

```bash
# 依赖：Python + python-docx
python build/check_content.py --dir content   # 内容格式与公式自检
python build/final_qa.py                      # 交付验收
python build/build_docx.py                    # 生成 docx（输出到 output/）
```

> 注意：`build/make_plan.py` 会**重新生成** `content/my/ch02_plan.txt`、`ch13_mixed.txt`、`appendix.txt`。
> 仓库中的这三个文件包含人工润色过的文字，重新运行该脚本会覆盖这部分润色。
