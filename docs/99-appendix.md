# 附录 C　最容易丢分的 18 个计算细节（考前速查）

| 1 | 负号 | 先数负号个数 |

| 3 | 洛必达 | 用之前先写"这是 $\frac00$ 型" |
| 4 | 等价无穷小 | 遇到加减结构改用泰勒展开 |
| 5 | 不定积分常数 | 写完立刻检查 $+C$ |
| 6 | 绝对值 | 记成 $\ln\vertx\vert$ |
| 7 | 上下限 | 写清 $F(b)-F(a)$ |
| 8 | 代换上下限 | 换元后立刻改上下限 |
| 9 | 参数方程二阶导 | 写公式再代数 |
| 10 | 隐函数求导 | 每出现一次 $y$ 就乘一个 $y'$ |
| 11 | 链式法则 | 画链式图再算 |
| 12 | 极值判别 | 先算 $A,B,C$ 再判 |
| 13 | 二重积分定限 | 画图后逐条写不等式 |
| 14 | 极坐标 | 写 $r$ 再积分 |
| 15 | 特征方程 | 三种情形背下来 |
